上一课区分了控制与转发。本课只看一条简化流表规则：匹配条件 → 动作。你将亲自改变规则，观察执行结果，为后续理解安全流量处理打基础。

本课用“目的 B/C”简写 MAC 条件：B 为 02:00:00:00:00:0b，C 为 02:00:00:00:00:0c。真实 OpenFlow 流项还包括优先级、计数器和指令等；本课只保留一条具体规则，避免引入规则冲突。原始依据：ONF OpenFlow 1.3.2，5.2–5.4。

三个小操作

  1. 安装“目的 B → 接口2”，发给 B，再发给 C：对比匹配和未匹配。
  2. 把规则改为“目的 C → 接口3”，点击安装，再发给 C：对比改规则前后。
  3. 把规则改为“目的 C → 丢弃”，点击安装，再发给 C：匹配成功一定会转发吗？

也可以故意把“目的 B”送到接口3，看看配置错误会怎样。这是你写的规则，不会被系统偷偷纠正。

边界：这是单表教学模拟；目的 MAC 已给定，不模拟 ARP；接口连接正常，规则持续有效。未匹配处理由本实验明确配置为丢弃，不代表所有 SDN 都这样处理。真实丢弃可通过无输出动作等方式实现。
